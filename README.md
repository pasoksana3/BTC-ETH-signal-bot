# MEXC Signal Bot — Diagnostic Build

Ця збірка зберігає поточну торгову логіку:
- 5m pattern: 4–6 однакових свічок → exhaustion → confirmation
- локальний 10m
- 15m + 1h MA filter
- MIN_SCORE=85
- TP1=0.50%, TP2=0.70%
- Telegram alerts only

Додано:
- [DIAG] статистику відсіву на етапах кожного повного циклу
- без зміни торгових порогів
- діагностика показує, де саме зникають кандидати

ВАЖЛИВО:
Це файл на основі переданого source `5m -> 10m -> 15m -> 1h`.
Він НЕ є адаптивною версією `1H ZONE + SWEEP + CHoCH + POI/FVG`, яка була в окремих Railway-логах.

Для GitHub:
1. заміни свій Python-файл на `bot.py`;
2. залиш змінні Telegram/MEXC як у своєму репозиторії;
3. задеплой;
4. подивись рядки `[DIAG]` після кількох циклів.

Не змінюй пороги вручну до отримання статистики.
